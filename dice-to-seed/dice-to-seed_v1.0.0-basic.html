    Write the words on paper by hand. Never photograph, paste, or retype them on a connected device.
    
  
    Use this file air-gapped. Save it, move it to an offline machine, open it, generate, close the browser. It makes no network requests, loads nothing external, and writes nothing to disk or browser storage.
    
  
    The length is fixed before the first roll. Hardened is the default. Changing 12 / 24 or transparent / hardened after you have started clears the box. Eighteen-word phrases are not offered.
    
  
    Transparent mode is exactly uniform, not approximately. The rolls form one base-6 integer. The tool rejects the top slice of the range that would not divide evenly into 2n, then reduces. About 1 sequence in 7,300 (12 words) or 86,000 (24 words). If it fires, discard every roll and start over. Do not add, remove, or edit a face to escape it.
    
  
    Hardened mode assumes the die is imperfect. After you confirm the set, face 6 is written as 0 and that cleaned line is SHA-256’d. That matches Ian Coleman’s Dice [1-6] when auto-detect is off, the type is Dice [1-6], and the word count is 12 or 24 (not “raw”). Paste him the original 1–6 faces, not the zeros: Dice [1–6] deletes 0. Auto-detect is on by default and will treat a 0–5 line as hex. 64 or 128 rolls leave spare entropy so a skewed die can still feed the hash. You give up tracing bits back to individual faces.
    
  
    The face tally is information, not an instruction. Uneven counts are normal. Re-rolling to even them biases the seed. A red strip under the tally means the set looks typed or from a dead die — clear it. An amber strip is a warning only; the phrase is still offered. Test a suspect die in a separate session, then generate with a die you trust.
    
  
    Verify before funding. Restore the phrase on a hardware wallet or a second independent BIP39 implementation and confirm identical addresses. Two implementations agreeing is the safety net; this file agreeing with itself is not.
    
  
    This is the Basic file. It never derives keys. The Full file adds the first three bech32 addresses, the account zpub, and a SeedQR after the phrase exists.
